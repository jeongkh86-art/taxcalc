건강보험료 시뮬레이터

  • 피부양자 유지 판정, 탈락 시 지역가입자 보험료
  • 지역가입자 보험료, 직장가입자 보수 + 보수 외 소득 보험료
  • 같은 소득, 재산일 때 직장가입자와 지역가입자 비교
  • 금융소득(이자·배당) 구간별 결과표
근거, 2026년 요율

건강보험료율 7.19%(국민건강보험법 시행령 §44①) · 재산보험료부과점수당 211.5원(시행령 §44②) · 장기요양보험료 = 건강보험료 × 13.14%(노인장기요양보험법 §9① · 시행령 §4 장기요양보험료율 0.9448% ÷ 7.19%, 소수 다섯째 자리 반올림)
상한 : 직장 보수월액보험료 9,183,480원, 보수 외 소득월액보험료·지역 4,591,740원 / 하한 : 직장·지역 20,160원(「월별 건강보험료액의 상한과 하한에 관한 고시」 보건복지부고시 제2025-222호, 2026.1월분부터)
소득 범위 = 이자·배당·사업·근로·연금·기타(시행령 §41①, 비과세 제외) · 분리과세 금융소득 1천만원 이하 미합산(시행규칙 §44① 단서) · 근로·연금 50% 평가, 나머지 100%(시행규칙 §44②③) · 지역 소득월액 28만원 이하 = 하한 보험료(시행규칙 §44③ 단서)
재산 = 재산세 과세표준 + 무주택 전월세 [보증금 + 월세 × 40] × 30% − 1억원 − 1세대1주택 주택담보대출 공제(최대 5천만원) → 60등급 점수(시행령 §42, §42의2, 별표 4 · 시행규칙 별표 8) · 자동차 부과 폐지(별표 4 제4호 삭제 2024.2.13)
피부양자 = 소득 합계 연 2천만원 이하 + 사업소득 없음(미등록·500만원 이하 예외) + 재산세 과세표준 5.4억 이하(5.4억~9억은 소득 1천만원 이하) · 기혼이면 부부 모두 소득요건 충족(시행규칙 §2, 별표 1의2)
소득 반영 시기 = 1~10월분 전전년도, 11~12월분 전년도 소득 · 연금은 늘 전년도(시행령 §41③)

① 가입 유형

시행규칙 별표 1 · 모르면 비워 두기 → 「탈락 가능」 + 채우면 결과 함께
대표 보수월액 = 사업소득 ÷ 12, 최고 근로자보다 낮으면 그 금액(시행령 §38③)

② 연간 소득만원 · 있는 그대로 입력 → 반영율 자동

입력 방법
  • [+ 소득 추가] → 소득 종류 선택 → 금액 입력
  • 반영율, 반영 금액은 자동 계산
  • 사업소득 = 매출이 아니라 소득금액(매출 − 필요경비) · 종합소득세 신고서 금액
  • 강연료, 원고료 = 받은 금액 그대로(필요경비 60% 자동 차감)
대상자 본인
배우자
반영율 근거

· 이자 + 배당 합계 1,000만원 이하 = 0%(분리과세 · 시행규칙 §44① 단서) · 1,000만원 초과 = 전액 100%
· 배당 종합과세(금융소득 2천만원 초과) = 배당가산액(Gross-up) 더한 금액 입력(소득세법 §17③)
· 사업, 기타 = 100% · 근로, 연금 = 보험료 50%(시행규칙 §44②③), 피부양자 판정은 100%
· 사업소득 종류 : 사업자등록·주택임대 = 1원이라도 피부양자 탈락 · 미등록(3.3% 프리랜서) = 500만원 이하 예외(별표 1의2)
· 강연료, 원고료 등 = 필요경비 60% 의제 → 소득금액 40%(소득세법 시행령 §87 1호의2) · 그 밖 기타소득 = 소득금액(수입 − 필요경비) 입력
· 직장가입자 모드 근로 = 지금 회사 보수 뺀 다른 근로소득만
· 분리과세 주택임대(2천만원 이하) = 수입금액 입력 → 필요경비 50%(등록 임대주택 60%), 다른 종합소득금액 2천만원 이하면 200만원(등록 400만원) 추가 차감(시행규칙 §44①3호 · 소득세법 §64의2②) — 다른 소득은 입력 금액으로 어림 확인 필요
· 연금 : 공적연금 = 그해 받은 전부(시행령 §41①5호) · 사적연금(연금저축·퇴직연금 등 연금계좌) = 조문상 포함(시행령 §41①5호 「소득세법 §20의3 소득」) · 공단 실무는 현재 미부과(정부가 부과 유예 — 언론 보도 기준) → 기본 0%, 위 칸 켜면 50% 확인 필요
· 양도소득, 퇴직소득 = 건보 소득 범위 밖(시행령 §41① — 이자·배당·사업·근로·연금·기타만) → 0% · 비과세 소득 = 0%
· 일용근로소득 = 원천징수로 끝나는 분리과세(소득세법 §14③2호) · 조문상 근로소득이나 종합소득 신고에 안 잡혀 0%로 둠 확인 필요
· 종교인소득 = 기타소득(소득세법 §21①26호, 근로소득 신고 선택 가능 §21④) → 「종교인소득」 칸 = 소득금액 입력 100%, 근로 선택이면 근로소득 칸
· 해외(국외원천) 소득 = 거주자는 종류대로 종합소득 → 이자, 배당, 사업 등 해당 칸에 원화 금액 입력

근거

· 공정시장가액비율 : 토지·건축물 70%, 주택 60% · 2026년 1세대 1주택은 3억 이하 43%, 6억 이하 44%, 6억 초과 45%(지방세법 시행령 §109①) · 과세표준상한제(지방세법 §110③)는 계산기에 안 넣음 — 고지서 과세표준이 정확
· 피부양자 재산요건은 개인별 과세표준 합(공제 없음), 지역 보험료는 세대 합 − 1억
· 주택담보대출 공제 = 대출잔액 × 공정시장가액비율, 그 주택 과세표준과 5천만원 중 작은 금액 한도(시행령 §42의2③1호) — 주택 과세표준이 기준시가 × 공정시장가액비율 이하인 주택만(§42의2②) · 전월세 대출 공제(무주택)는 안 넣음

미반영 항목, 확인 필요

· 지역가입자 경감(노인·장애·섬 등) = 경감율 칸에 직접 입력(선택) · 법정 경감율 자동 계산은 안 넣음
· 2022.9 개편 피부양자 탈락자 한시 경감(4년) = 2026.8월 종료(보도 기준) → 안 넣음 확인 필요
· 부양요건 = 선택 칸 · 비워 두면 「탈락 가능」으로 보고 채우면 유지 결과를 함께 표시 · 형제자매 판정은 뺌(2026-10-29)
· 직장 vs 지역 비교 : 직장 쪽 배우자는 피부양자 판정(탈락하면 배우자만 지역) · 개인사업자 대표 보수월액 = 사업자등록 사업소득 ÷ 12(최고 근로자 보수월액 하한) · 회사 부담분은 따로 표시
· 재건축 사업소득 예외(별표 1의2 1호 다목), 소득월액 조정신청(시행령 §41의2 · 퇴직·폐업으로 소득 줄면 조정 가능)은 안 넣음
· 보험료 끝수는 원 미만 버림 — 고지서와 몇 원 차이 날 수 있음 확인 필요
· 금융소득 1천만원 이하 미합산은 피부양자 소득 합계에도 같게 적용(공단 실무) 확인 필요
· 세대 재산은 대상자 부부만 합산 — 같은 세대 다른 세대원 재산·소득이 있으면 더해야 함
